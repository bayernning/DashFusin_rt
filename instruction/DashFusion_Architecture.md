## 损失函数计算

```
总损失 = 预测损失 + λ × 对比损失

┌───────────────────────────────────────┐
│ 预测损失 (Lpred)                      │
│                                       │
│ MSE(pred, label)                     │
│                                       │
└───────────────────────────────────────┘

┌───────────────────────────────────────┐
│ 对比损失 (Lcon)                       │
│                                       │
│ 语义对齐损失:                         │
│ • NT-Xent(文本, 音频)                │
│ • NT-Xent(文本, 视觉)                │
│                                       │
│ 监督对比损失:                         │
│ • NT-Xent(文本, 文本_样本集)         │
│ • NT-Xent(视觉, 视觉_样本集)         │
│ • NT-Xent(音频, 音频_样本集)         │
│ • NT-Xent(多模态, 多模态_样本集)     │
│                                       │
└───────────────────────────────────────┘

λ = 0.2
```

## 关键机制详解

### 1. 时间对齐机制

```
目标: 将音频和视觉特征对齐到文本时间轴

步骤:
1. 文本作为Query: Q = Xt
2. 音频作为K,V:   K,V = Xa
   视觉作为K,V:   K,V = Xv

3. 计算注意力:
   Attention(Q, K, V) = softmax(QK^T/√d) V

4. 融合:
   H = Xt + Attention(Xt, Xa) + Attention(Xt, Xv)

结果:
• H的每个时间步都融合了对应的音频和视觉信息
• 解决了不同模态的时间不同步问题
```

### 2. 层次化瓶颈融合机制

```
初始: 8个瓶颈tokens

┌────────────────────────────────┐
│ Layer 1                        │
│                                │
│ Step 1: Transformer重分配信息  │
│   B¹ = Transformer(H)[:, :8]  │
│                                │
│ Step 2: 瓶颈收集各模态信息     │
│   B¹ += Multi-CA(B¹, Xt, Xa, Xv)│
│   ↑ 同时从三个模态获取信息     │
│                                │
│ Step 3: 各模态从瓶颈获取信息   │
│   Xt += CA(Xt, B¹)            │
│   Xa += CA(Xa, B¹)            │
│   Xv += CA(Xv, B¹)            │
│   ↑ 双向信息流动               │
│                                │
└────────────────────────────────┘
        ↓ 压缩: keep 4 tokens
┌────────────────────────────────┐
│ Layer 2                        │
│ (重复上述过程，token=4)        │
└────────────────────────────────┘
        ↓
最终融合特征

优势:
✓ 双向信息流动(vs 单向时间对齐)
✓ 渐进压缩，过滤冗余
✓ 强制学习最重要特征
```

### 3. 监督对比学习的样本构建

```
对于每个样本i:

┌─────────────────────────────────┐
│ Sample1 (anchor)                │
│   - 文本特征: t_i               │
│   - 视觉特征: v_i               │
│   - 音频特征: a_i               │
│   - 多模态: h_i                 │
│   - 标签: y_i                   │
└─────────────────────────────────┘
            ↓
    根据余弦相似度检索
            ↓
┌─────────────────────────────────┐
│ Sample2 (6个样本)               │
│                                 │
│ 正样本(2个): 同类 & 高相似      │
│   ├─ 样本j: y_j=y_i, sim>阈值 │
│   └─ 样本k: y_k=y_i, sim>阈值 │
│                                 │
│ 负样本(4个): 异类               │
│   ├─ 困难负样本(2个)            │
│   │   ├─ 样本m: y_m≠y_i, 高相似│
│   │   └─ 样本n: y_n≠y_i, 高相似│
│   └─ 简单负样本(2个)            │
│       ├─ 样本p: y_p≠y_i, 低相似│
│       └─ 样本q: y_q≠y_i, 低相似│
└─────────────────────────────────┘

对比学习矩阵:
       t_i  t_j  t_k  t_m  t_n  t_p  t_q
       v_i  v_j  v_k  v_m  v_n  v_p  v_q
       a_i  a_j  a_k  a_m  a_n  a_p  a_q
       h_i  h_j  h_k  h_m  h_n  h_p  h_q

每种特征计算一次NT-Xent损失
```

## 计算复杂度对比

```
方法             操作                   复杂度(MAdds)
───────────────────────────────────────────────────
Concatenation   简单拼接                    0
                [Xt, Xa, Xv]
                ↓
                Classifier

Self-Attention  拼接 + 自注意力          324M
                [Xt, Xa, Xv]
                ↓
                Self-Attn (全序列)
                ↓
                Classifier

Cross-Attn      跨模态注意力              73M
                Xt ← CA(Xt, Xa)
                Xt ← CA(Xt, Xv)
                ↓
                Classifier

Bottleneck      瓶颈融合                 162M
                B(固定8) ← Multi-CA
                Modalities ← CA(B)

HBF (Ours)      层次化瓶颈融合           145M ✓
                Layer1: B(8) ...
                Layer2: B(4) ...
                (渐进压缩)

性能: HBF > Concat+SA ≈ Bottleneck > Cross-Attn > Concat
效率: HBF(145M) < Bottleneck(162M) < Concat+SA(324M)
```

## 训练过程时间线

```
Epoch 1
  ├─ 更新相似度矩阵 (update_matrix)
  │   └─ 收集所有训练样本的T, V, A特征
  │   └─ 计算样本间余弦相似度
  │
  ├─ 训练迭代
  │   ├─ Batch 1
  │   │   ├─ 获取sample1
  │   │   ├─ 根据相似度矩阵采样sample2(6个)
  │   │   ├─ 前向: pred, loss = model(s1, s2)
  │   │   └─ 反向: loss.backward() + step()
  │   │
  │   ├─ Batch 2
  │   └─ ...
  │
  └─ 验证 + 保存最佳模型

Epoch 2
  ├─ 不更新矩阵 (使用Epoch1的矩阵)
  └─ 训练...

Epoch 3
  ├─ 更新相似度矩阵
  └─ ...
```

## 实现技巧

### 1. 瓶颈token的初始化
```python
# 从时间对齐后的H中选取前p个token作为初始瓶颈
# 而不是随机初始化
query = Transformer(H)[:, :p]
```

### 2. 样本检索的效率优化
```python
# 预先计算所有样本的特征
# 每2个epoch更新一次，避免每个batch都重新计算
if epoch % 2 == 1:
    update_matrix(...)  # 更新相似度矩阵
```

### 3. 对比学习的indices构建
```python
# 精心设计的indices_tuple确保正负样本配对正确
# anchor_idx: [0,0,1,1,2,2,...]  每个anchor重复
# pos_idx:    [7,14,8,15,...]    对应的正样本
# neg_idx:    [3,4,5,6,...]      对应的负样本
```

### 4. 渐进式压缩策略
```python
# 每层瓶颈数量减半
keep = initial_query_len  # 8
for level in range(depth):
    query = query[:, :keep]
    keep = max(1, keep // 2)  # 8 -> 4 -> 2 -> 1
```

这种设计迫使模型在每一层都筛选最重要的信息！
